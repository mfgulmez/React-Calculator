# React Calculator
A simple and responsive calculator built with React. This application performs basic arithmetic operations with real-time visual feedback. Designed for clarity, ease of use, and educational purposes.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Division by zero protection
- Clear and delete functionality
- Operator chaining logic (e.g. 5+4*3)
- Styled with CSS for a neat, calculator-like UI
- Memory function placeholders (MC, M+, M-, MR - not yet implemented)
